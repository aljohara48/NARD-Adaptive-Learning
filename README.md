# NARD – AI-Driven Adaptive Educational Game for Children with Dyscalculia<img width="468" height="13" alt="image" src="https://github.com/user-attachments/assets/ed214ae4-0b6f-4efa-8ceb-fa7cddf39834" />


NARD is an AI-powered educational application designed to provide
adaptive mathematics practice for elementary school students.

## Overview

The application personalizes question difficulty based on student
performance using rule-based assessment and reinforcement learning.

## Key Features

- Adaptive learning experience
- Reinforcement Learning using Q-Learning
- Machine Learning-based difficulty assessment
- Arabic-first user interface
- Student progress tracking
- Teacher dashboard and data export
- Firebase authentication and cloud database

## Technologies

- Swift / SwiftUI
- Firebase
- Python
- Machine Learning
- Reinforcement Learning
- Q-Learning
- Data Analytics

## Machine Learning

The system uses cognitive and question-related features to estimate
difficulty levels and personalize the learning experience.

For later learning levels, a Q-Learning approach is used to select
appropriate question difficulty based on student performance.
